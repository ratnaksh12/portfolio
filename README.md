# Ratnaksh Tyagi — Portfolio

Animated single-page portfolio (AI Builder). Live via GitHub Pages: https://ratnaksh12.github.io/portfolio/

- `index.html` — the whole site: HTML, CSS, JS and the embedded portrait in one file. No build step.
- `v1/` — the previous version of the portfolio, kept for reference.

To add LinkedIn / GitHub links, fill in the `LINKS` object near the top of the `<script>` in `index.html`.
